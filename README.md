# SIMRS RS USHI — Versi Demo Statis (GitHub Pages)

Tampilan SIMRS RS USHI untuk semua peran dengan data contoh.

- Buka `index.html` → **Masuk** → ketik username demo (mis. `dokter1`, `perawat`, `kasir`, `pasien`), password bebas.
- Versi ini **tidak menyimpan data** (GitHub Pages tidak menjalankan PHP/MySQL). Versi lengkap ada di folder `simrs-ushi` (XAMPP).

## Upload ke GitHub Pages
1. Buat repository baru, upload **isi** folder ini ke root repository.
2. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
3. Buka `https://<username>.github.io/<nama-repo>/`.
